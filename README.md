# Library Management System

A console-based Library Management System developed in Java using Object-Oriented Programming concepts.

## Features

- Add Book
- View Books
- Issue Book
- Return Book
- Capacity Validation
- Book Search by ID

## OOP Concepts Used

- Encapsulation
- Abstraction
- Inheritance
- Method Overriding
- Constructor Chaining
- this Keyword
- super Keyword

## Technologies Used

- Java
- OOP
- Arrays
- Scanner Class
